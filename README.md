# E.A. Rodgers Investigative Group

Initial custom website build for E.A. Rodgers Investigative Group.

## Hosting

Designed for deployment with Netlify from this GitHub repository.

## Current structure

- `index.html` — homepage
- `assets/styles.css` — responsive styling
- `assets/site.js` — interactive client tabs
- `netlify.toml` — Netlify deployment and security headers

## Design rule

No black, charcoal, or dark full-width section backgrounds. The approved visual palette uses white, warm ivory, soft gray, sand, and very light blue-gray backgrounds with dark navy typography and accents.
