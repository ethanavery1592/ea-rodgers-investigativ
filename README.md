# Broadwater Investigative Group

Custom website build for Broadwater Investigative Group.

## Hosting

Designed for deployment with Netlify from this GitHub repository.

## Current structure

- `index.html` — homepage
- `assets/styles.css` — responsive styling
- `assets/site.js` — interactive client tabs and page enhancements
- `assets/client-pages.css` — dedicated client page styling
- `assets/photos.css` — Lowcountry photography treatment
- `netlify.toml` — Netlify deployment and security headers

## Design rule

No black, charcoal, or dark full-width section backgrounds. The approved visual palette uses white, warm ivory, soft gray, sand, and very light blue-gray backgrounds with dark navy typography and accents.

## Brand

- Name: Broadwater Investigative Group
- Monogram: BI
- Tagline: Integrity. Discretion. Results.
